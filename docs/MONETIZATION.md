# Як Lesefreund заробляє гроші і як усе підключити

## 1. Реклама (Google AdMob) — уже вбудована

У коді вже є (`app/js/ads.js`, налаштування в `app/js/config.js` → `ADS`):

| Де | Тип реклами | Для кого |
|---|---|---|
| Кожні **5 сторінок** книжки | межсторінкова (interstitial) | тільки без Premium |
| **2 ролики → 1 година Premium** (екран Premium) | за винагороду (rewarded) | без Premium |
| Відкрити книжку з великого каталогу | за винагороду | без Premium |
| Додати свою книжку з Project Gutenberg | за винагороду | без Premium |

Зараз стоять **офіційні тестові ID Google**, тож реклама показується з позначкою «Test Ad». Щоб заробляти:

1. Зареєструйтеся на **admob.google.com** (той самий Google-акаунт, що й Play Console).
2. *Apps → Add app* → Android → «Lesefreund». Скопіюйте **App ID** (`ca-app-pub-…~…`).
3. *Ad units → Add*: створіть **Interstitial** і **Rewarded**. Скопіюйте їхні ID (`ca-app-pub-…/…`).
4. Вставте:
   - App ID → `android/app/src/main/AndroidManifest.xml` (рядок `com.google.android.gms.ads.APPLICATION_ID`);
   - ID блоків → `app/js/config.js` → `ADS.android`, і `testing: false`.
5. Те саме для iOS: App ID → `ios/App/App/Info.plist` (`GADApplicationIdentifier`), ID блоків → `ADS.ios`.
6. `npm run sync`, зібрати, опублікувати. Перші гроші з’являються в AdMob наступного дня; виплата — від 70 € на місяць.

⚠️ Ніколи не натискайте на свою рекламу і не просіть друзів: AdMob блокує акаунт назавжди.
Згода на рекламу в ЄС (GDPR) вже обробляється в коді (UMP, `requestConsentInfo`); у AdMob → *Privacy & messaging* створіть повідомлення GDPR.

## 2. Підписка Premium

Ціни в `app/js/config.js` (`PLANS`): 3,99 €/міс і 29,99 €/рік. Справжня оплата:

- Найпростіше — **RevenueCat** (безкоштовно до 2 500 $ доходу на місяць): один SDK для Google Play і App Store,
  плагін `@revenuecat/purchases-capacitor`. У Play Console → *Monetize → Subscriptions* створюєте `premium_month` і `premium_year`.
- Google бере 15 % з підписок (з першого дня для підписок), Apple — 15 % для малих розробників.
- Кнопка «Оформити» вже є (`renderPremium` в `app/js/app.js`, позначено `TODO`): туди викликати `Purchases.purchasePackage()`.

## 3. Статистика: скільки завантажили, скільки читає, скільки заробили

| Що | Де дивитись |
|---|---|
| Встановлення, видалення, оцінки, країни | **Google Play Console** → Statistics |
| Дохід від реклами | **AdMob** → Reports |
| Дохід від підписок | Play Console → Financial reports (або RevenueCat → Overview) |
| iPhone | **App Store Connect** → Analytics / Sales |
| «Скільки людей читає зараз», популярні книжки, скільки книжок додали | **Firebase Analytics** (безкоштовно): плагін `@capacitor-firebase/analytics`, події `book_open`, `book_import`, `page_turn`. Realtime-звіт показує, скільки людей зараз у застосунку |

Локальна адмінка (`npm run admin`) містить посилання на всі ці панелі й керує промокодами (створити, відкликати → Premium знімається).

## 4. Чесні метрики

Фальшивих «ботів-читачів» у застосунку немає і не буде: Google Play забороняє вводити користувачів в оману
(політика *Deceptive Behavior*), і за це видаляють застосунок. Рейтинг «Популярні» чесний: оцінки читача
плюс реальні завантаження книжок у Project Gutenberg. Коли буде Firebase, туди можна додати справжні оцінки всіх користувачів.

## 5. Розмір застосунку

Зараз застосунок містить: ~100 тис. слів словника Лесі (≈31 МБ), обкладинки, 50 книжок офлайн, каталог на ~1500 книжок
(тексти завантажуються під час відкриття й зберігаються). Google Play приймає застосунки будь-якого розміру;
Duolingo великий через відео й аудіо, а не тому, що «так треба». Ліміт Play — 200 МБ базового пакета.
Якщо захочете більше офлайн-книжок у самому застосунку — `npm run bulk` + Play Asset Delivery.

## 6. Публікація

- **Google Play**: акаунт розробника 25 $ (один раз). *Build → Generate Signed Bundle (.aab)* в Android Studio.
  Потрібні: іконка 512×512 (`resources/icon-only.png`), банер 1024×500, 2–8 скриншотів, політика конфіденційності (URL),
  анкета *Data safety* (реклама AdMob = «збирає ідентифікатор реклами»), вікова категорія.
- **App Store**: Apple Developer 99 $/рік, потрібен Mac з Xcode (`npm run ios`) → *Product → Archive*.

## 7. Просування (ідеї)

- **TikTok / Reels / Shorts**: формат «одне слово з книжки на день» — Лесі показує слово з Кафки чи Грімм, переклад, як вимовляти.
  «Читаю Кафку німецькою з нуля — день 1», «5 німецьких слів, яких нема в підручниках».
- Ролики «до/після»: незнайомий абзац → торкнувся → зрозумів.
- Цитати-картинки з водяним знаком Lesefreund (кнопка «Цитата» у читалці): люди самі діляться в Instagram/Telegram.
- Промокоди блогерам-викладачам німецької (Premium на місяць) через адмінку.
- Telegram-канали для тих, хто вчить німецьку (українці в Німеччині, студенти).
- ASO: у назві в Play — «Lesefreund: німецька через книжки», ключові слова «вивчити німецьку», «Deutsch lernen».
