# Lesefreund — немецкие книги с мгновенным переводом

Приложение для изучения немецкого через чтение. Библиотека книг от A1 до C1:
**нажал на слово — увидел перевод**, **зажал и выделил фразу — перевелась целиком**.

## Что умеет

- 📚 **Библиотека** — 7 книг (A1, A2, B1, B2, C1), фильтр по уровню, прогресс чтения.
  A1–A2 бесплатно, B1–C1 — по подписке.
- 👆 **Перевод слова по нажатию** — с озвучкой (🔊), сохранением в «Мои слова» и кнопкой «Перевести предложение».
- ✍️ **Перевод выделенного** — зажать текст, выделить цитату → кнопка «Перевести выделенное».
- 🎓 **Обучение при первом запуске** — 4 экрана, на втором выбирается язык перевода
  (16 языков: русский, украинский, английский, польский, турецкий и др.).
- 🗂️ **Мои слова** — личный словарь с контекстом из книги.
- ⚙️ **Настройки** — язык перевода и интерфейса (RU/EN), размер шрифта, тёмная тема, выбор переводчика.
- ★ **Подписка 1 €/мес** + **промокоды** (на час, день, неделю, месяц, навсегда — любую длительность).
- 📴 Работает офлайн (PWA), ставится на телефон как приложение («Добавить на главный экран»).

### Переводчики

| Режим | Что это |
|---|---|
| Авто (по умолчанию) | Gemini, если указан ключ, иначе бесплатный онлайн |
| Бесплатный онлайн | MyMemory, без ключа (лимит ~5000 символов в день на устройство) |
| Google Gemini | Точный перевод **с учётом контекста предложения** + начальная форма, артикль, часть речи. Ключ: [aistudio.google.com](https://aistudio.google.com) → вставить в Настройках |
| Офлайн | Встроенный мини-словарь частых слов (`app/data/mini-dict.js`) |

Переводы кешируются, повторное нажатие на слово работает мгновенно и без интернета.

## Запуск

Нужен только [Node.js](https://nodejs.org) 18+. Никаких `npm install`.

```bash
npm start        # приложение → http://localhost:8080
npm run admin    # админ-панель промокодов → http://localhost:4000
```

Оба сервера выводят в консоль адрес вида `http://192.168.x.x:…` — его можно открыть **с телефона в той же Wi‑Fi сети**.

## Админ-панель промокодов

1. `npm run admin`. При первом запуске в консоли появится **пароль** — сохраните его
   (или задайте свой: `ADMIN_PASSWORD=мойпароль npm run admin`).
2. Откройте панель на компьютере или телефоне, войдите.
3. Создайте коды: длительность (кнопки «1 час», «1 неделя», «Навсегда»… или своё значение),
   количество, префикс, «активировать до» (срок жизни самого кода), заметка. Можно задать свой код, например `WINTER2026`.
4. Нажмите **«Опубликовать в приложение»** — обновится `app/promo-pack.json`.
5. Выпустите обновление приложения — новые коды заработают у пользователей.

Как устроена защита: коды в открытом виде лежат только у вас в `admin/data/codes.json`
(папка в `.gitignore`, в репозиторий не попадает). В приложение уходят только **SHA-256 хеши** кодов,
поэтому вытащить коды из файлов приложения нельзя. Отключённый в админке код исчезнет из пака при следующей публикации.
Ещё можно экспортировать все коды в CSV.

> ⚠️ Ограничение офлайн-схемы: код помечается использованным **на конкретном устройстве**.
> Один и тот же код можно ввести на разных телефонах. Если нужны строго одноразовые коды —
> следующий шаг — небольшой сервер (например Firebase / Supabase), который отмечает активации.

## Структура

```
app/                 приложение (PWA, чистый JS без сборки)
  index.html
  css/style.css
  js/app.js          экраны: обучение, библиотека, читалка, словарь, подписка, настройки
  js/translate.js    переводчики (Gemini / MyMemory / офлайн) + кеш
  js/promo.js        проверка промокодов
  js/store.js        настройки, прогресс, подписка (localStorage)
  js/i18n.js         тексты интерфейса RU/EN и список языков перевода
  data/books.js      книги — сюда добавлять новые
  data/mini-dict.js  офлайн-словарь
  promo-pack.json    пак промокодов (генерирует админка)
admin/
  server.js          локальный сервер админки (без зависимостей)
  public/index.html  интерфейс админки
tools/serve.js       локальный сервер для приложения
```

### Как добавить книгу

Допишите объект в `app/data/books.js`: `id`, `title`, `author`, `level` (A1…C1), `premium` (true/false),
`color`, `emoji`, `description` {ru, en} и `chapters` с массивом абзацев.
