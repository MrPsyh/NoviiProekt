# Lesefreund — німецькі книжки з перекладом за дотиком

Застосунок для Android та iOS (і веб-версія), щоб учити німецьку, читаючи справжню літературу:
**торкнувся слова — бачиш переклад**, **затиснув і виділив фразу — переклад цілої цитати**,
**незнайоме слово — у словник, а потім учиш його картками**, як у Quizlet.

## Запуск

Потрібен [Node.js](https://nodejs.org) 18+.

```bash
npm install
npm start            # веб-версія → http://localhost:8080 (і з телефону в тій самій Wi‑Fi)
npm run admin        # адмін-панель промокодів → http://localhost:4000
```

### Android та iOS (Capacitor)

Проєкти вже створено в папках `android/` та `ios/`.

```bash
npm run android      # копіює застосунок і відкриває Android Studio → ▶ Run
npm run ios          # те саме для Xcode (лише на Mac)
```

Після будь-яких змін у `app/` виконуйте `npm run sync`.
Для публікації: Android Studio → *Build → Generate Signed Bundle* (.aab для Google Play),
Xcode → *Product → Archive* (App Store).

## Переклад

Застосунок не використовує Gemini. Порядок джерел (`app/js/translate.js`):

1. **Готовий словник книжок** `app/dict/<мова>.json`: миттєво й офлайн. Зібрати: `GOOGLE_TRANSLATE_KEY=… npm run dict -- uk ru en`.
2. **Кеш на телефоні**: кожне слово перекладається лише один раз.
3. **Google Translate**:
   - зараз — безкоштовний публічний endpoint Google прямо з телефона (у кожного користувача свій ліміт, сервер не потрібен);
   - для релізу рекомендовано **офіційний Google Cloud Translation API через ваш сервер**
     `server/translate-proxy.js` (ключ лежить лише на сервері, переклади кешуються для всіх користувачів).
     Впишіть адресу в `TRANSLATE_PROXY_URL` у `app/js/config.js`. Ціна: 500 тис. символів/міс безкоштовно, далі ~20 $ за 1 млн.
4. Запасні: MyMemory, вбудований міні-словник.

> Публічний endpoint Google неофіційний: Google може його обмежити. Для стабільного комерційного
> застосунку переходьте на проксі з офіційним ключем, у коді для цього вже все готово.

## Книжки й авторські права

Усі книжки — **суспільне надбання** (тексти з німецької Wikisource) або власні тексти Lesefreund.
Розбір, що можна, а що ні («Маленький принц», Муракамі, Ремарк, Достоєвський, японська та українська література)
і як отримати ліцензію: **[docs/COPYRIGHT.md](docs/COPYRIGHT.md)**.

```bash
npm run import                                   # імпорт усього з tools/catalog.json (Wikisource)
npm run import -- kafka-verwandlung --force      # перезалити одну книжку
npm run gutenberg -- search Dostojewski          # пошук у Project Gutenberg (перевіряє, чи вільний переклад)
npm run gutenberg -- add 12345 --id dostojewski-x --collection slavic --level C1 --premium
npm run covers                                   # палітурки для книжок без скану
python3 tools/build-catalog.py                   # великий каталог з pg_catalog.csv (дзеркало Gutenberg)
python3 tools/filter-covers.py                   # прибрати згенеровані обкладинки Gutenberg
node tools/gutenberg-curated.js                  # вбудувати відібрані книжки (tools/gutenberg-picks.json)
python3 tools/build-lexicon.py <kaikki.jsonl>    # перебудувати словник Лесі (app/lexicon/)
```

Нова книжка = запис у `tools/catalog.json` (назва сторінки Wikisource, рівень, колекції, опис трьома мовами).

## Промокоди

1. `npm run admin`. При першому запуску в консолі з’явиться **пароль** (або `ADMIN_PASSWORD=… npm run admin`).
2. Створюєте коди: на 1 годину, день, тиждень, місяць, назавжди або на свій термін; пачкою або свій код (`WINTER2026`).
3. **«Опублікувати в застосунок»** → оновлюється `app/promo-pack.json` → `npm run sync` → нова версія в магазинах.

У застосунок потрапляють лише SHA-256 хеші кодів, тож самі коди звідти не дістати. Код позначається використаним
на конкретному пристрої. Строго одноразові коди для всіх пристроїв потребують сервера.

## Структура

```
app/                    застосунок (HTML/CSS/JS без збирання)
  js/app.js             навігація, онбординг, бібліотека, Premium, налаштування
  js/reader.js          читалка, переклад слова/фрази, картинка-цитата
  js/learn.js, srs.js   картки, тест, письмо, інтервальне повторення
  js/translate.js       Google Translate + кеш + готовий словник
  js/stickers.js        сова Лесі (SVG-стікери), досягнення
  js/config.js          ціни, адреса сервера перекладу, ліміти
  books/                тексти книжок (JSON) + index.json
  covers/               обкладинки (SVG)
  fonts/                Literata (OFL)
android/, ios/          нативні проєкти (Capacitor)
admin/                  адмін-панель промокодів (локально, без залежностей)
server/translate-proxy.js  сервер для офіційного Google Translation API
tools/                  імпорт книжок, обкладинки, словник
docs/COPYRIGHT.md       авторські права
```
