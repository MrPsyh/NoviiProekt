# 🎲 LazyGame

Telegram-бот с настольными играми для компаний: **🐊 Крокодил**, **🏚 Бункер**,
**🔪 Мафия**, **🪢 Виселица**, **🎭 Правда или Действие**. Карточки, слова и
виселица приходят картинками.

## Возможности

- **🐊 Крокодил** — ведущему в ЛС приходит слово (картинкой), он объясняет его в
  чате, остальные угадывают. Кто угадал — новый ведущий. Есть счёт.
- **🏚 Бункер** — случайная катастрофа, у каждого карточка-персонаж (картинка в ЛС),
  по кругу раскрываете характеристики и голосуете, кого оставить снаружи.
- **🔪 Мафия** — роли (мафия / доктор / комиссар / мирные), ночные действия кнопками
  в ЛС, дневное голосование в чате, автоопределение победителя.
- **🪢 Виселица** — кооп: бот загадывает слово, игроки пишут буквы, за ошибки
  достраивается виселица (картинкой).
- **🎭 Правда или Действие** — бот выбирает игрока, тот жмёт кнопку и получает
  задание; ход передаётся дальше.
- **🕵️ Шпион (Brawl Stars)** — все, кроме шпиона, получают в ЛС одного бравлера
  (с фото); намекаете на него и вычисляете шпиона голосованием. Два режима:
  шпион знает / не знает, что он шпион.
- **🧠 Викторина** (соло в ЛС) — 7 вопросов с вариантами, ответы кнопками, счёт.
- **⚡ Реакция** (группа) — кто быстрее нажмёт кнопку, очки за раунды.
- **🗳 Кто из нас?** (группа) — пати-голосование «кто скорее всего…».
- **🙈 Я никогда не…** (группа) — классика для компании, «было / не было».
- **🧠 Повтори** (соло) — запомни и повтори растущую последовательность.
- **🔤 Анаграммы** (соло) — собери слово из перемешанных букв.
- **Соло-режим в личке** (`/play`): Виселица и Викторина один на один с ботом.
- **🎮 Мини-апп (Telegram Web App)** — красивый выбор игр, запуск прямо в чат.
- **🏆 Рекорды** (`/top`) — топы игроков по каждой игре, по чату и по всему миру,
  картинкой + мини-апп `webapp/records.html` (выбор игры и масштаба).
- Приветственное фото и оформление сообщений (жирный текст, цитаты).
- Лобби с кнопками «Войти / Выйти / Начать».
- Выбор языка (RU/EN/UK) и сложности (Крокодил/Виселица) перед стартом.
- Крокодил: слова не повторяются + кнопка «🔄 Заменить слово» у ведущего.

<b>Групповой режим — правила поведения:</b>
- Остановить игру (`/stop`) может ведущий <b>или любой админ</b> группы.
- Меню (выбор игры/языка/сложности/настроек) — приватное: чужую панель трогать
  нельзя, плюс кулдаун 30 сек на открытие нового меню.
- Если за 90 сек не набралось минимума игроков — лобби само отменяется.
- В закрытых играх (Мафия, Бункер) посторонние (кто не в игре) писать не могут:
  их сообщение удаляется, выдаётся мут на 60 сек (нужны права админа боту).
- **Настройки** на чат: лимиты игроков по каждой игре (`/settings`).
- Меню команд по вводу «/».
- Лёгкое добавление новых игр (см. `lazygame/games/`).

## ⚠️ Права администратора

После добавления в группу **сделайте бота администратором** (Настройки группы →
Администраторы → Добавить). Без этого Telegram скрывает от бота сообщения в чате,
и Крокодил/Виселица не работают. Бот сам напомнит об этом при добавлении и
проверит права перед `/newgame`.

## Установка и запуск

```bash
# 1. зависимости
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. токен
cp .env.example .env
# открой .env и вставь свой токен от @BotFather

# 3. запуск
python -m lazygame.bot
```

Затем добавь бота в групповой чат, выдай ему права админа (чтобы видел
сообщения) и напиши `/newgame`.

> ⚠️ Чтобы бот мог прислать тебе слово/роль/карточку — **каждый игрок должен
> заранее написать боту `/start` в личку.**

## 🔑 Где хранить токен (ВАЖНО)

Токен бота — это пароль. Кто его знает, тот управляет ботом.

- **Никогда** не коммить токен в репозиторий и не пиши его в коде.
- Локально токен лежит только в файле `.env` — он в `.gitignore` и в GitHub не попадёт.
- Если запускаешь через **GitHub Actions / хостинг** — положи токен в
  **Settings → Secrets and variables → Actions → New repository secret**
  (имя `BOT_TOKEN`) и читай его из окружения. В файлы репозитория — нельзя.
- Если токен где-то засветился (чат, скриншот, лог) — сразу отзови его:
  **@BotFather → /mybots → твой бот → API Token → Revoke current token.**

## 🎮 Мини-апп (Telegram Web App)

Веб-апп лежит в `webapp/` (один `index.html`). Он показывает список игр и по
кнопке «Играть» отправляет боту, какую игру запустить (`tg.sendData`).

Чтобы включить:
1. Выложи `webapp/` на любой HTTPS-хостинг. Проще всего — **GitHub Pages**:
   Settings → Pages → Source: ветка, папка `/webapp` (или перенеси `index.html`
   в корень/`docs`). Получишь адрес вида `https://<user>.github.io/NoviiProekt/`.
2. Добавь этот адрес в `.env`: `WEBAPP_URL=https://<user>.github.io/NoviiProekt/`
3. Перезапусти бота. В личке появится кнопка **🎮 Открыть LazyGame** и кнопка-меню.

Без `WEBAPP_URL` бот работает как обычно, просто без мини-аппа.

## 🕵️ Изображения Brawl Stars (для «Шпиона»)

Бот отправляет фото бравлера из `lazygame/assets/brawlers/<id>.png`. Если файла
нет — показывает нейтральную карточку с именем (без изображения персонажа).

Как добавить оригинальные арты:
- запусти на своём компьютере `python scripts/download_brawlers.py` (тянет
  портреты из Brawlify CDN в `lazygame/assets/brawlers/`), **или**
- скачай официальный **Supercell Fan Kit** и разложи портреты как `<id>.png`.

Арты в git не коммитятся (см. `.gitignore`).

> **Дисклеймер.** Это неофициальный фанатский проект. Brawl Stars и изображения
> персонажей — собственность Supercell. Используются в соответствии с
> [Supercell Fan Content Policy](https://supercell.com/en/fan-content-policy/).
> Проект не создан, не спонсирован и не одобрен Supercell.

## 🗄 Данные и тесты

- **Персистентность:** настройки чатов, язык и статистика хранятся в SQLite
  (`lazygame/data/lazygame.db`, в git не коммитится) и переживают перезапуск.
  Активные игровые комнаты намеренно только в памяти (они временные); зависшие
  игры авто-очищаются фоновой задачей.
- **Тесты:** `pip install -r requirements-dev.txt && pytest` — покрыта логика
  всех игр, настроек и локализации. CI гоняет их на каждый push
  (`.github/workflows/tests.yml`).

## 🚀 Деплой 24/7

Бот должен крутиться постоянным процессом. Любой вариант ниже — токен задаётся
только через переменную окружения `BOT_TOKEN`, в образ/репозиторий он не попадает.

### Docker (локально или на VPS)
```bash
# положи токен в .env (BOT_TOKEN=...), затем:
docker compose up -d --build        # запуск в фоне, автоперезапуск
docker compose logs -f              # смотреть логи
docker compose down                 # остановить
```

### VPS без Docker (systemd)
```bash
pip install -r requirements.txt
# создай /etc/systemd/system/lazygame.service с ExecStart=.../python -m lazygame.bot
# и Environment=BOT_TOKEN=..., затем:
sudo systemctl enable --now lazygame
```

### Railway / Render (бесплатно, из GitHub)
1. Подключи этот репозиторий.
2. Тип сервиса — **Worker** (не Web): команда `python -m lazygame.bot`
   (уже прописана в `Procfile`), либо собери по `Dockerfile`.
3. В **Variables / Environment** добавь `BOT_TOKEN` со своим токеном.
4. Деплой. Бот будет работать постоянно.

> ⚠️ Запускай только **один** экземпляр бота на токен. Если бот крутится в двух
> местах сразу, Telegram вернёт ошибку `409 Conflict`.

## Команды

| Команда     | Что делает                                  |
|-------------|---------------------------------------------|
| `/newgame`  | групповая игра (в чате)                      |
| `/play`     | соло-игра в личке (Виселица, Викторина)      |
| `/settings` | настройки: лимиты игроков                    |
| `/go`       | начать игру (ведущий) — также кнопкой        |
| `/stop`     | остановить текущую игру (ведущий)            |
| `/skip`     | Крокодил: пропустить слово                   |
| `/score`    | Крокодил / Виселица: таблица очков           |
| `/reveal`   | Бункер: раскрыть свою характеристику         |
| `/vote`     | Бункер: ведущий запускает голосование        |

## Структура

```
lazygame/
├── bot.py              # точка входа, все хэндлеры
├── config.py           # чтение токена из .env
├── cards.py            # генерация карточек-картинок (Pillow)
├── data/               # слова и данные для карточек
├── settings.py         # настройки чата (лимиты игроков)
└── games/
    ├── base.py         # движок: игрок, комната, менеджер
    ├── crocodile.py
    ├── bunker.py
    ├── mafia.py
    ├── hangman.py
    ├── truth_or_dare.py
    └── quiz.py          # соло-викторина

webapp/index.html                             # мини-апп (Telegram Web App)
Dockerfile · docker-compose.yml · Procfile   # файлы деплоя (в корне репозитория)
```

Добавить новую игру: наследуй `BaseGame`, реализуй `start()` и зарегистрируй
класс в `lazygame/games/__init__.py` (`GAME_REGISTRY`).
